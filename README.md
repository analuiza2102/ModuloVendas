# 🧾 Sistema de Cadastro de Usuários - Java Swing + Hibernate

Este projeto é uma aplicação desktop feita em **Java Swing**, utilizando os padrões **MVC** e a biblioteca **Hibernate ORM** para persistência de dados em banco.

## ✨ Funcionalidades

- Autenticação de usuário com tela de login
- Cadastro de usuários com campos: Nome, Login, Senha, Ativo
- Listagem e pesquisa de usuários
- Ações de **criar**, **alterar**, **excluir** e **consultar**
- Interface gráfica responsiva e moderna
- Estilização escura (dark mode) personalizada

## 🛠️ Tecnologias Utilizadas

- Java SE (Swing / AWT)
- Hibernate ORM
- Banco de dados relacional (MySQL, MariaDB ou outro compatível)
- MVC (Model-View-Controller)
- JDK 8 ou superior

## 🎨 Design da Interface

A interface do sistema foi construída com base em uma paleta escura, utilizando tons de cinza, rosa e branco para melhor legibilidade e estética moderna.
